# Product

## Register

product

## Users

Junior developers onboarding to Kubernetes at companies adopting cloud-native infrastructure. They use it on company time or evenings, often self-directed. They're capable but unfamiliar with the Kubernetes mental model. They want to feel like they're becoming real engineers, not like they're going through a course.

## Product Purpose

Kubepath Tutorial makes Kubernetes YAML and CLI concepts learnable through simulated hands-on practice. Users work through concepts, practice kubectl commands in a fake terminal, debug broken manifests, and take quizzes. Success = a junior dev who can read, write, and debug Kubernetes YAML without feeling lost.

## Brand Personality

Precise. Grounded. No-nonsense.

The tutorial should feel like a senior engineer sitting beside you — capable, direct, not condescending. Not a teaching app. A workspace that teaches.

## Anti-references

- Codecademy, Scrimba, Khan Academy: pastel colors, friendly bubbles, emoji-heavy, beginner-coded aesthetics. Never.
- Generic SaaS dashboards: gray sidebar + blue primary button + neutral card grid.
- kubernetes.io docs: raw, unstyled, table-heavy.
- "Hacker terminal" cliché: neon green on pure black, scanlines, CRT glow effects.

## Design Principles

1. **Practice what you preach.** The UI should feel like a terminal environment, not a tutorial about terminals. Commit to the dark, technical register.
2. **Confidence through clarity.** Junior devs are anxious. Clear visual hierarchy and immediate feedback (points, completion states) reduce that anxiety without infantilizing.
3. **Earn the green.** Success states, completions, and points should feel earned. Not celebratory confetti — quiet, satisfying confirmation.
4. **Density with breathing room.** Code and YAML are inherently dense. The surrounding UI must give them room without going sparse and empty.
5. **One tool, not a course.** The experience is a workspace. Navigation is minimal. Content is primary.

## Accessibility & Inclusion

WCAG AA. Support reduced motion. Ensure terminal color scheme meets contrast requirements (no low-contrast green-on-green). Monospace text at readable minimum size (13px+).
